참고 자료에서 뽑은 규칙(픽시브 해설, 저장소에 이미지는 넣지 않음 — 저작권):
- 물방울은 **빛이 오는 위쪽이 짙고**, 빛이 통과해 모이는 **아래쪽이 밝다**([涙や汗に使える水滴](https://www.pixiv.net/artworks/99745782), CLIP STUDIO [涙のメイキング](https://www.clipstudio.net/oekaki/archives/169163) — "광원 쪽이 어두워진다, 그림자 속에 밝은 부분").
- 위 빛은 원형 띠가 아니라 **창 모양 덩어리 + 작은 점**, 아래 가장자리에 **가는 빛 한 줄**, 바닥에 **떨어진 그림자 + 그 속 반사광**.
- 비추천: 흰색만(우유), **검은 윤곽선(붕 뜸)**, 일반 음영(물방울 같지 않음). 애니풍 윤곽은 위가 가늘고 아래가 굵다.
- 밝은 빛은 가로 띠가 아니라 **윤곽을 따라 감싸며**(覆い焼き/加算) 밝힌다([ちょっと厚みのある水滴](https://www.pixiv.net/artworks/83365425)). 젤리는 면적 절반에 옅은 빛① + 위 가운데에 강한 빛②(가산) + 반사광([ゼリーの描き方](https://www.pixiv.net/artworks/80299456)).
- 가장자리에 색(청록·분홍)을 얇게 겹치면 유리 느낌([雫の描き方](https://www.pixiv.net/artworks/149475879)).
- **투명/불투명 돌의 차이**(가장 중요 — [宝石の絵を描くときの個人的ポイント](https://www.pixiv.net/artworks/126990198)): 불투명한 돌은 위가 밝고 아래 그림자(지금 메뉴 오브가 이쪽이라
  "유리"가 아니라 "플라스틱"처럼 보였다). 투명한 돌은 **광원 쪽 가장자리가 어둡고, 반대편 안쪽에 빛이 들어와 밝다**. 색은 4가지(진한 바탕·중간·밝은 투과광·흰색)면 충분.
- 둥근 보석 칠하는 순서([丸みのある宝石をそれっぽく塗る](https://www.pixiv.net/artworks/118357764)): 바탕 → 그림자 2단(가장자리에 바탕색 테를 남김) → 가운데를 오버레이로 더 진하게 →
  하이라이트(스크린). "칠 얼룩이 조금 남아도 된다" — 완벽한 CSS 그라데이션이 오히려 싸 보이는 이유.
- 수집 방법: 픽시브 공개 API `https://www.pixiv.net/ajax/search/illustrations/<태그>?word=<태그>&order=date_d&mode=safe&s_mode=s_tag&type=illust`,
  이미지 목록 `/ajax/illust/<id>/pages`, 이미지는 `Referer: https://www.pixiv.net/` 로 받는다. 고품질 거르기는 "`<태그> 1000users入り`" 태그.
  레딧은 자동 접근이 막혀 결과 없음, 핀터레스트는 로그인·스크립트 없이 이미지 안 나옴(시도함).
- 사용자 지시(2026-10-17): 더 깊게·전문적으로 조사할 것. 연령 등급은 상관없다고 함(성인). 단 픽시브 R-18 은 로그인 필요라 지금 방법으론 안 보인다.

```bash
curl -sS -o clt.zip https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip
unzip -q -o clt.zip -d /opt/android-sdk/cmdline-tools && mv /opt/android-sdk/cmdline-tools/cmdline-tools /opt/android-sdk/cmdline-tools/latest
yes | /opt/android-sdk/cmdline-tools/latest/bin/sdkmanager --sdk_root=/opt/android-sdk "platforms;android-35" "build-tools;35.0.0" "platform-tools"
echo "sdk.dir=/opt/android-sdk" > /home/user/kIkI/local.properties   # .gitignore 대상
cd /home/user/kIkI && ./gradlew testDebugUnitTest
```
